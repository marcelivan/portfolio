# Marcel Rivera-Baillargeon | Personal Portfolio

Public professional portfolio at https://marcelivan.github.io/portfolio/

## Intent
A concise, accessible front door for systems architecture, revenue operations, governed automation, integrations, and human-directed AI. This site is separate from private architecture and professional evidence repositories.

## Evidence and disclosure boundary
- Reference designs are original, generalized descriptions. They are **not** statements that an employer deployed, adopted, or achieved outcomes from these designs.
- No confidential employer implementations, customer or employee data, internal tickets, source code, incident descriptions, metrics, or nonpublic information.
- Public project links point only to existing public personal repositories.
- Promote specific employer work or results only after documented disclosure approval and verification.
- Avoid fabricated credentials, team sizes, certifications, financial impact, or business results.

## Publishing
Static HTML, CSS, and a minimal script. GitHub Pages serves the main branch root. No build system, cookies, third-party analytics, or form data collection.

## Maintenance
Update contact and project links only when needed. Prefer clear, durable descriptions over a recurring content-production obligation.
